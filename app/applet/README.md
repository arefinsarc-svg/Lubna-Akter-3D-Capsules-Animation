# Lubna Akter - Professional Portfolio & Administrative Dashboard

A production-ready, highly polished professional portfolio and interactive administrative dashboard for **Lubna Akter** (Clinical Pharmacy | Pharmaceutical Research & Pharmacology | Medical Writing & Drug Information).

## Features

- **Dynamic Hero & Profile Section**: Showcases professional summary, contact links, interactive 3D molecular viewer toggle, and verified high-resolution niqabi pharmacist profile photo.
- **Interactive Administrative Dashboard**: Live portfolio data editing, content management, analytics overview, contact message logs, and resume customization.
- **Multilingual Support**: Fully localized English and Bengali language switching.
- **Theme Customization**: Clinical light mode and dark research lab mode.
- **Research & Publications Showcase**: Comprehensive display of pharmacology papers, review articles, and clinical posters.
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewports.

---

## Tech Stack

- **React 18** with **TypeScript**
- **Vite** for ultra-fast bundling and production builds
- **Tailwind CSS v4** for modern styling
- **Lucide React** for professional iconography
- **Framer Motion** for smooth, natural animations

---

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

---

## Netlify Deployment Instructions

1. **Repository Setup**: Push this repository to GitHub.
2. **Netlify Site Creation**:
   - Log in to [Netlify](https://app.netlify.com).
   - Click **Add new site** -> **Import an existing project**.
   - Connect to your GitHub provider and select this repository.
3. **Build Settings**:
   - **Build Command**: `npm run build`
   - **Publish Directory**: `dist`
4. **Environment Variables**: None required for client-side storage mode.
5. Click **Deploy Site**.
